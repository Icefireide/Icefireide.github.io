How I work

How I set up a show so there’s as little as possible to fix on the day.

The build is finished two days out

Scenes, music, transitions and graphics are done and frozen 48 hours before doors. Rehearsal is for finding problems while there’s still time to fix them.

The show runs off a live control sheet

Graphics run off a Google Sheet wired into the broadcast. Team names, scores, rosters, lower thirds: change a cell and it changes on air. Nothing gets re-exported mid-show, and anyone on the crew with the link can update it without touching the production machine.

Scope is agreed in writing first

A contractor agreement and a statement of work before anything starts, with deliverables, timeline and price settled up front. Anything added later goes through a change order so we both know what’s been agreed.

Documented so your team can run it

Tooling ships with an operator manual, and the control sheet is something your team already knows how to use. If they need to run it without me for a scheduling clash, a second stage, or next season, they can.
