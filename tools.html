Tooling

Software I’ve written for my own shows and for clients. Graphics control, map bans, rosters and stats pulled straight out of the game. Every shot on this page comes off the tool itself, running on mock match data, so it’s what actually goes on air.

Two ways to get it: I bring it to a show I’m already producing, or you license it and your own producer runs it. An overlay is an addition to the game, not something that sits on top of it, and everything here is built so one person can drive it mid-broadcast. Rate sheets for each tool are on the way; until then, ask.

League of Legends

Runs on Division One’s league broadcasts

  • In-game HUD with live stats off the game feed
  • Pick/ban draft display
  • Team and player graphics, driven from the league data
  • Google Sheets control: change a cell, it changes on air
  • Observer companion for a dedicated camera op

In-game HUD and draft stills are coming once I next run the game feed; they need a live match to render.

Valorant

Built for MilkTeaBoards, also run on Division One

  • Map veto carousel and pick/ban
  • Agent select and starting-lineup reveals
  • In-game camera and graphics overlay
  • Post-game scoreboard and head-to-head
  • Match stats database with auto-detect polling

Rocket League

Runs on Division One’s Rocket League broadcasts

  • Live scoreboard and HUD off game telemetry
  • Post-game results and match history
  • vMix instant replay goal capture, marked automatically
  • Per-goal clip export with an MVP highlight folder
  • Camera picture-in-picture

Riftbound

Riot’s trading card game

  • Overlay with each player’s rune pool and a shared victory track
  • Showdown, where two battlefields can be fought over at once
  • Live deck lists rendered from imported decklists
  • Caster camera scene
  • Card library with a pre-show sweep for missing art

Riftbound card art is the property of Riot Games. It appears here only to show software I built.
